## ✨ Δυνατότητες

- Γρήγορο: ένα βίντεο 1080p ενός λεπτού μετατρέπεται σε περίπου 7 δευτερόλεπτα
- Όλες οι συνηθισμένες μορφές: MP4, MOV, WebM, AVI, MKV, WMV, FLV και άλλες (έως 500 MB)
- 28 στυλ: απλό pixel art, λουλούδια, καρδιές, σχήματα, LED, ASCII και Μπράιγ
- Παλέτες (αυτόματη, Game Boy, PICO-8, CGA, σέπια…), dithering, φωτεινότητα/αντίθεση, περικοπή
- Εξαγωγή σε βίντεο MP4/WebM στην αρχική ταχύτητα ή σε GIF που επαναλαμβάνεται ατέλειωτα
- Αποθήκευσε μια ιστοσελίδα σε ένα αρχείο με το μήνυμά σου και εφέ γραφομηχανής (100–500 KB, χωρίς internet)
- Διαθέσιμο σε 24 γλώσσες, που επιλέγονται αυτόματα από τον περιηγητή
- Τρέχει εξ ολοκλήρου στον υπολογιστή σου — τα βίντεό σου δεν ανεβαίνουν πουθενά

## 📥 Λήψη (Windows)

1. Κατέβασε το `PixelArtVideo-Windows-x64.zip` από την [τελευταία έκδοση](https://github.com/noms6/pixel-art-video/releases/latest).
2. Αποσυμπίεσέ το και τρέξε το `VideoASCIIArtConverter.exe` — ο περιηγητής ανοίγει μόνος του. Δεν χρειάζεται Python.

> Αν το Windows SmartScreen εμφανίσει προειδοποίηση, πάτησε **Περισσότερες πληροφορίες → Εκτέλεση οπωσδήποτε** (η εφαρμογή δεν είναι υπογεγραμμένη).

## 🧭 Οδηγίες χρήσης

1. Ανέβασε ένα βίντεο (σύρε και άφησε ή επίλεξε αρχείο). Αν θέλεις, άνοιξε πρώτα τις ρυθμίσεις μετατροπής.
2. Έλεγξε την προεπισκόπηση. Άλλαξε τις ρυθμίσεις και μετάτρεψε ξανά χωρίς νέο ανέβασμα.
3. Πάτησε ✨ ΕΝΑΡΞΗ ✨, διάλεξε στυλ και ρύθμισε μέγεθος, πυκνότητα και χρώματα.
4. Γράψε το μήνυμά σου και κατέβασε βίντεο ή GIF, αποθήκευσε τη σελίδα ή μοιράσου τη.
