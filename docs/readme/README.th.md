## ✨ ความสามารถ

- รวดเร็ว: วิดีโอ 1080p ยาว 1 นาทีแปลงเสร็จในราว 7 วินาที
- รองรับรูปแบบยอดนิยม: MP4, MOV, WebM, AVI, MKV, WMV, FLV และอื่น ๆ (สูงสุด 500 MB)
- 28 สไตล์: พิกเซลอาร์ตธรรมดา ดอกไม้ หัวใจ รูปทรง LED ASCII และอักษรเบรลล์
- ชุดสี (อัตโนมัติ, Game Boy, PICO-8, CGA, ซีเปีย…) ดิทเทอริง ความสว่าง/คอนทราสต์ ตัดช่วง
- ส่งออกเป็นวิดีโอ MP4/WebM ด้วยความเร็วเดิม หรือ GIF ที่เล่นวนไม่รู้จบ
- บันทึกหน้าเว็บไฟล์เดียวพร้อมข้อความและเอฟเฟกต์เครื่องพิมพ์ดีด (100–500 KB ใช้งานออฟไลน์ได้)
- มีให้ใช้ 24 ภาษา เลือกอัตโนมัติตามเบราว์เซอร์
- ทำงานบนคอมพิวเตอร์ของคุณทั้งหมด — วิดีโอไม่ถูกอัปโหลดไปที่ใดเลย

## 📥 ดาวน์โหลด (Windows)

1. ดาวน์โหลด `PixelArtVideo-Windows-x64.zip` จาก [รุ่นล่าสุด](https://github.com/noms6/pixel-art-video/releases/latest)
2. แตกไฟล์แล้วเปิด `VideoASCIIArtConverter.exe` — เบราว์เซอร์จะเปิดเองอัตโนมัติ ไม่ต้องติดตั้ง Python

> หาก Windows SmartScreen แจ้งเตือน ให้คลิก **ข้อมูลเพิ่มเติม → เรียกใช้ต่อไป** (แอปยังไม่ได้ลงนามดิจิทัล)

## 🧭 วิธีใช้

1. อัปโหลดวิดีโอ (ลากมาวางหรือเลือกไฟล์) หากต้องการ ให้เปิดการตั้งค่าการแปลงก่อน
2. ตรวจดูตัวอย่าง เปลี่ยนการตั้งค่าแล้วแปลงใหม่ได้โดยไม่ต้องอัปโหลดซ้ำ
3. กด ✨ เริ่ม ✨ เลือกสไตล์ แล้วปรับขนาด ความหนาแน่น และสี
4. เขียนข้อความ แล้วดาวน์โหลดวิดีโอหรือ GIF บันทึกหน้า หรือแชร์

## 🚀 เรียกใช้จากซอร์สโค้ด

```bash
pip install -r requirements.txt
python start_app.py
```
