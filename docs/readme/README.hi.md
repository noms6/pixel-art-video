## ✨ विशेषताएँ

- तेज़: 1 मिनट का 1080p वीडियो लगभग 7 सेकंड में बदल जाता है
- सभी आम फ़ॉर्मैट: MP4, MOV, WebM, AVI, MKV, WMV, FLV और अन्य (500 MB तक)
- 28 शैलियाँ: सादा पिक्सेल आर्ट, फूल, दिल, आकृतियाँ, LED, ASCII और ब्रेल
- पैलेट (स्वचालित, Game Boy, PICO-8, CGA, सेपिया…), डिदरिंग, चमक/कंट्रास्ट, काट-छाँट
- मूल गति में MP4/WebM वीडियो या लगातार चलने वाले GIF के रूप में निर्यात
- आपके संदेश और टाइपराइटर प्रभाव के साथ एक-फ़ाइल वेब पेज सहेजें (100–500 KB, ऑफ़लाइन चलता है)
- 24 भाषाओं में उपलब्ध, ब्राउज़र के अनुसार अपने-आप चुनी जाती है
- पूरी तरह आपके कंप्यूटर पर चलता है — आपके वीडियो कहीं अपलोड नहीं होते

## 📥 डाउनलोड (Windows)

1. [नवीनतम रिलीज़](https://github.com/noms6/pixel-art-video/releases/latest) से `PixelArtVideo-Windows-x64.zip` डाउनलोड करें।
2. इसे निकालें और `VideoASCIIArtConverter.exe` चलाएँ — ब्राउज़र अपने-आप खुल जाएगा। Python की ज़रूरत नहीं।

> अगर Windows SmartScreen चेतावनी दे, तो **अधिक जानकारी → फिर भी चलाएँ** पर क्लिक करें (ऐप पर डिजिटल हस्ताक्षर नहीं है)।

## 🧭 उपयोग कैसे करें

1. वीडियो अपलोड करें (खींचकर छोड़ें या फ़ाइल चुनें)। चाहें तो पहले रूपांतरण सेटिंग्स खोलें।
2. पूर्वावलोकन देखें। सेटिंग्स बदलें और दोबारा अपलोड किए बिना फिर से बदलें।
3. ✨ शुरू करें ✨ दबाएँ, शैली चुनें और आकार, घनत्व व रंग समायोजित करें।
4. अपना संदेश लिखें, फिर वीडियो या GIF डाउनलोड करें, पेज सहेजें या साझा करें।
