# Eski terminal ASCII scriptleri

Web uygulamasından bağımsız, terminalde çalışan ilk sürümler. Ana uygulama bunları kullanmaz.

```
python legacy/video_to_ascii.py video.mp4 cikti.txt 80 10     # dosyaya ASCII
python legacy/video_to_ascii_color.py video.mp4 120 10         # terminalde renkli oynat
```
